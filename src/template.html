Questions.

Is it free?

Yes. Every control, look, the sound and haptics engine, and the SwiftUI files are MIT. Use them in anything.

Do haptics work on iPhone?

On Android they use the vibration API. On iPhone, Safari has no vibration API, so web haptics play from iOS 18 on. The SwiftUI versions use the Taptic Engine on any iPhone.

Does it need a framework?

No. Each control is one web component with no dependencies, so it works in plain HTML, React, Vue, Svelte or anything else that renders HTML.

Can you make a custom control for my product?

Yes. Detent is made by 37degree, a design studio that takes custom work: controls, interfaces and sites for your product.
